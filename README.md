# TecnoMarket - Simulador de compra online

Proyecto final JS : tienda de tecnología con catálogo, carrito, cálculo de envío y confirmación de compra.

## Estructura
- `index.html`
- `css/styles.css`
- `js/api.js` (fetch con async/await, try/catch/finally), `js/storage.js` (localStorage), `js/app.js` (DOM y lógica)
- `data/productos.json`, `data/envios.json`
- `assets/img/`

## Librerías
Bootstrap 5, SweetAlert2 y Toastify (por CDN).
